# Release Notes — Version 10.0.0

**TAG:** `v10.0.0` / `v10-schema-adapter-ml-foundation`

## Architecture Changes
- **Scraper Schema v1.0**: upgraded VLR match parser extracting detailed overview, performance, and economy stats.
- **Match Adapter (`utils/match_adapter.py`)**: Centralized adapter layer that normalizes legacy Gen 1, Gen 2, and new Schema v1.0 match objects into a unified interface.
- **Team Registry (`utils/team_registry.py`)**: Canonical team name mapping and alias resolution.
- **ML Engine**: Transition from raw JSON training to an ML feature store, temporal dataset generator, model training, evaluation, and backtesting framework.

## Supported Data Formats
- **Gen 1**: Legacy match JSON format with basic team score and map summary.
- **Gen 2**: Intermediate scraper format with detailed map round histories.
- **Schema v1.0**: Latest high-fidelity format with overview, segment breakdowns, player combat/clutch stats, and economy histories.

## Current Statistics
- **Matches processed**: 2029 raw match JSON files in `data/raw/`.
- **Schema Adapter Version**: 1.0
- **Model Version**: v10 ML Pipeline Baseline
